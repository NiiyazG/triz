# Морфологический анализ + Cross-Consistency Assessment

> Статус: **canonical**. Источник: Fritz Zwicky, развит Tom Ritchey. Первоисточник: Ritchey, T. General Morphological Analysis. https://www.swemorph.com/ma.html

Морфологический анализ структурирует многомерную неформализуемую проблему как произведение параметров на их значения (условия), а затем через Cross-Consistency Assessment (CCA) отсеивает несовместимые комбинации, получая «пространство решений».

## Входные условия

- задача имеет несколько независимых измерений (параметров) с дискретными вариантами;
- полный перебор вручную невозможен или нетривиален;
- параметры неформализуемы численно (политика, стратегия, дизайн).

## Процедура

1. **Определи параметры** задачи (измерения), точно определи каждый.
2. **Задай значения/условия** для каждого параметра (дискретный спектр).
3. **Построй морфологическое поле** (Zwicky box): число конфигураций = произведение числа условий.
4. **Проведи CCA**: попарно сравни условия на совместимость (логическую, эмпирическую, затем нормативную).
5. **Выдели пространство решений** — внутренне согласованные конфигурации.
6. **Исследуй конфигурации** как сценарии/стратегии, задавая драйверы.

## Три типа несовместимости в CCA

- **логическая** — противоречие по сути понятий;
- **эмпирическая** — практически невероятная/неправдоподобная связь;
- **нормативная** — исключается по этическим/политическим основаниям (применяй после логической и эмпирической).

## Важно (pitfall)

Попарная совместимость условий **не гарантирует** совместимость всей конфигурации из многих параметров. Требуй ограничения более высокого порядка и проверяй целостный механизм каждой финальной конфигурации, а не только парные связи.

## Ограничения применимости

- Сила в покрытии пространства, слабость в глубине: конфигурация — гипотеза, требующая проверки.
- Число конфигураций растёт экспоненциально; удерживай параметры немногочисленными и хорошо определёнными.

## Проверка

- [ ] параметры определены однозначно и независимы;
- [ ] CCA фиксирует тип несовместимости (логическая/эмпирическая/нормативная);
- [ ] финальные конфигурации проверены на целостность, а не только попарно;
- [ ] выбраны 1–3 конфигурации для дальнейшей проработки.
