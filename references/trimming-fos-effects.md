# Тримминг, перенос признаков, FOS и научные эффекты

## Тримминг

Цель — удалить компонент, сохранив его полезную функцию. Перед удалением определи носителя функции и кандидата, который примет функцию:

- объект функции выполняет её сам;
- другой компонент системы принимает функцию;
- компонент надсистемы принимает функцию;
- необходимость функции устраняется изменением условий.

После тримминга сформулируй новую задачу реализации перенесённой функции.

## Перенос признаков

Сравни базовую систему с альтернативной, которая лучше по целевому признаку. Перенеси механизм полезного признака, не копируя всю систему и её недостатки.

## Function-Oriented Search

1. Обобщи функцию без привязки к текущей отрасли.
2. Найди ведущие области, где такая функция выполняется эффективнее.
3. Выдели физический/организационный механизм.
4. Адаптируй механизм к ограничениям задачи.
5. Проверь реализуемость и доказательства.

## Научные эффекты

Не выдумывай эффект по названию. Для каждого эффекта укажи источник, входные условия, выходной эффект, диапазон применимости и ограничения. В software научные эффекты часто заменяются проверяемыми алгоритмическими или архитектурными механизмами; это должно быть явно маркировано как адаптация.
