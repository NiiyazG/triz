# Software-шпаргалка

> Быстрые эвристики, не замена полному анализу и не канонический источник ТРИЗ.

## Быстрый старт (15 секунд)

1. Назови конфликт: «Если ускорить X, ломается Y»
2. Найди пару в таблице Software-конфликтов ниже
3. Примени 2-3 приёма

## Software-конфликты: быстрые рецепты

| Конфликт | Быстрый рецепт |
|---|---|
| Latency vs Throughput | 1 Дробление + 26 Копирование: шардирование + реплики |
| Consistency vs Availability | 15 Динамичность + 19 Периодическое: eventual consistency + фоновая синхронизация |
| Security vs UX | 2 Вынесение + 24 Посредник: OAuth-провайдер + отдельный сервис MFA |
| Dev velocity vs Code quality | 1 Дробление + 23 Обратная связь: модули + CI с авто-проверками |
| Scalability vs Simplicity | 5 Объединение + 17 Другое измерение: API Gateway + multi-tier |
| Deploy speed vs Stability | 15 Динамичность + 11 Подушка: canary deploy + автооткат |

| Microservices vs Debuggability | 5 Объединение + 24 Посредник: unified logging + distributed tracing |

## Техника безопасности: главные антипаттерны

| ❌ Не делай | ✅ Делай |
|---|---|
| 1 Дробление: не дроби на 50 наносервисов сразу | 3-5 сервисов по доменам, дроби по мере боли |
| 10 Предв. действие: не кэшируй всё подряд | Кэшируй только read-heavy, явный TTL + стратегия инвалидации |
| 23 Обратная связь: не алерть на каждый чих | Только actionable алерты, SLO-based подход |
| 6 Универсальность: не делай «фреймворк для всего» | Универсализируй только переиспользуемое в ≥3 местах |
| 5 Объединение: не пихай всё в монорепо без инструментов | Только с shared configs, affected-детекцией в CI |
| 26 Копирование: не копируй БД на каждый микросервис | Read-реплики (один source of truth), CQRS для сложного |

## Как читать эту шпаргалку

1. **Если конфликт ясен** → сразу в таблицу «Software-конфликты», бери рецепт.
2. **Если конфликт нестандартный** → открывай `software-contradictions.md` для полной таблицы.
3. **Если нужно глубоко понять приём** → открывай `software-techniques.md`.
4. **Если нужен полный разбор с ИКР и веполем** → возвращайся в основной `SKILL.md`.

**Главное правило**: шпаргалка — для скорости. Не заменяет анализ противоречий из основного навыка. Если рецепт не сработал за 1 итерацию — переходи на полный конвейер.
