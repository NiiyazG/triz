# Латеральное мышление и шесть шляп

> Статус: **canonical**. Источник: Edward de Bono. Первоисточники: https://en.wikipedia.org/wiki/Lateral_thinking ; https://en.wikipedia.org/wiki/Six_Thinking_Hats

Латеральное мышление — намеренный уход от линейной (вертикальной) логики для генерации идей через провокацию. Шесть шляп — параллельное мышление по ролям для структурированного рассмотрения. Применяй для снятия ментальных блоков и полного обзора, не вместо ТРИЗ.

## Латеральное мышление — провокация (po)

- Сформулируй **провокацию** (намеренно ложное/абсурдное утверждение), помеченную `po`.
- Используй приём «движение» (movement): не «это неверно», а «что из этого следует, куда это ведёт?».
- Приёмы: инверсия, преувеличение, искажение, случайное слово, «побег» (escape).
- Собери ценные направления и верни их в реальность.

## Шесть шляп (параллельное мышление)

| Шляпа | Роль |
|---|---|
| Белая | факты, информация, без оценок |
| Красная | эмоции, интуиция, без обоснования |
| Чёрная | риски, слабости, осторожность |
| Жёлтая | выгоды, оптимизм, ценность |
| Зелёная | креативность, альтернативы, провокации |
| Синяя | управление процессом, мета-уровень |

Последовательность шляп задаёт структуру рассмотрения; все «надевают» одну шляпу одновременно.

## Связь с ТРИЗ

Зелёная шляпа ≈ генераторы (SIT/синектика), чёрная ≈ диверсионная проверка, белая ≈ реестр доказательств. Используй шляпы для организации обсуждения, а ТРИЗ — для модели противоречия и снятия.

## Ограничения применимости

- Генератор/организатор мышления, не даёт критериев истинности.
- Провокации требуют дисциплины «движения» — иначе это просто мозговой штурм.

## Проверка

- [ ] провокации помечены `po` и обработаны движением, а не отвергнуты;
- [ ] в шляпах соблюдена параллельность (одна шляпа на всех одновременно);
- [ ] итоги переданы в ТРИЗ/decision-analysis для проверки.
