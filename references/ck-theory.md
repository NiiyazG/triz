# C-K theory — генерация при нехватке знания

> Статус: **canonical**. Источник: Armand Hatchuel, Benoît Weil. Первоисточник: Hatchuel, A., Weil, B. C-K design theory: an advanced formulation. Res Eng Design 19, 181–192 (2009). https://link.springer.com/article/10.1007/s00163-008-0043-4

C-K theory моделирует проектирование как взаимодействие двух пространств: **C** (Concepts — концепты без логического статуса) и **K** (Knowledge — знание с логическим статусом). Применяй, когда нет готового противоречия, но нужно породить новый объект из доступного знания.

## Ключевые понятия

- **Пространство C:** предложения, для которых пока нельзя сказать «истина/ложь» (напр. «летающий велосипед»).
- **Пространство K:** установленное знание (законы, факты, известные решения).
- **Дизайн:** одновременное расширение C и K; новое знание делает концепт решаемым.

## Четыре оператора

| Оператор | Действие |
|---|---|
| **K → C** (дизъюнкция) | Преврати свойство знания в новый концепт: «если знаю X, можно ли сделать Y, которого нет в K?» |
| **C → K** (конъюнкция) | Добавь к концепту свойства из K, сузив его до проверяемого (проверка требует знания). |
| **C → C** (разделение/расширение) | Разбей концепт на под-концепты или добавь новые, ещё недоказуемые свойства. |
| **K → K** | Получи новое знание (эксперимент, поиск) для продвижения дизайна. |

## Процедура

1. Запиши исходный концепт в C (без статуса истины/ложи).
2. Разделяй C: для каждого под-концепта спрашивай, какое знание K требуется для решения.
3. Ищи недостающее знание (K → K): эксперимент, литература, эффекты.
4. Возвращай знание в концепт (K → C), порождая новые возможности.
5. Повторяй, пока концепт не станет решаемым/опровергнутым в K.

## Связь с ТРИЗ

C-K дополняет ТРИЗ на этапе, где противоречие ещё не сформулировано: ТРИЗ работает «от противоречия», C-K — «от неизвестного объекта». ФП можно рассматривать как частный случай разделения концепта в C.

## Ограничения применимости

- Не даёт готовых принципов решения (в отличие от 40 приёмов) — это логика порождения, а не каталог.
- Требует дисциплины в разделении C и K: «недоказуемое» нельзя молча считать знанием.

## Проверка

- [ ] концепт записан без преждевременного статуса истины/ложи;
- [ ] каждый шаг помечен оператором (C→K / K→C / C→C / K→K);
- [ ] недостающее знание названо конкретно и проверяемо.
