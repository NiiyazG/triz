# OTSM Network of Problems — «большая картина» сложных задач

> Статус: **canonical**. Источник: Николай Хоменко, OTSM (General Theory of Powerful Thinking). Первоисточник: Khomenko, N., De Guio, R. (2007). OTSM Network of Problems. https://link.springer.com/chapter/10.1007/978-0-387-75456-7_8

Network of Problems (NoP) — метод повышения формализации описания проблемной ситуации и получения «большой картины» для решения сложных междисциплинарных задач средствами ТРИЗ/OTSM. Применяй, когда противоречий несколько и они взаимосвязаны.

## Входные условия

- несколько взаимосвязанных недостатков/противоречий;
- нет единой корневой причины, которую можно выделить изолированно;
- задача междисциплинарная или системная (технология + процесс + организация).

## Процедура

1. **Собери проблемы** — сформулируй каждую как отдельный узел (проблему), не смешивая с решениями.
2. **Свяжи узлы** — проведи рёбра «является причиной / влияет на» между проблемами.
3. **Проанализируй bottleneck-узлы** — узлы с несколькими входящими связями часто указывают на скрытое противоречие (или систему противоречий).
4. **Разверни противоречия** — переведи ключевые проблемы в технические/физические противоречия, образуя сеть противоречий.
5. **Строй частичные решения** — для каждого противоречия предложи частичное решение; частичные решения могут конфликтовать друг с другом.
6. **Анализируй «короткие связи»** — прямые рёбра между проблемой и решением, которые можно использовать как быстрые выигрыши.
7. **Выбери направление** — сфокусируйся на bottleneck и его противоречии.

## Результат

Список проблем, превращённых в противоречия; карта влияний; выбранное «узкое место» для дальнейшего применения ТРИЗ.

## Ограничения применимости

- Не заменяет решение противоречий — это метод **постановки/структурирования**, а не снятия.
- Сеть — модель, а не истина; рёбра причинности должны быть проверяемыми, а не ассоциативными.
- Для больших сетей нужна итерация: сначала высокоуровневая карта, затем детализация ключевого узла.

## Проверка

- [ ] проблемы отделены от решений;
- [ ] bottleneck-узел выделен и обоснован;
- [ ] ключевые проблемы переведены в противоречия (а не оставлены как жалобы);
- [ ] рёбра причинности помечены факт/гипотеза.
