# Синектика — аналоговый прорыв инерции

> Статус: **canonical**. Источник: William J.J. Gordon. Первоисточник: https://www.sciencedirect.com/topics/psychology/synectics

Синектика — метод творческого решения через систематическое использование аналогий для преодоления психологической инерции. Применяй, когда команда/модель «застряла» в знакомых решениях.

## Четыре типа аналогий

| Тип | Механизм | Пример |
|---|---|---|
| **Прямая** | поиск решения в другой области с похожей функцией | как природа/другая отрасль решает это |
| **Личная (эмпатия)** | представить себя объектом/элементом | «я — поток данных, что я чувствую?» |
| **Символическая** | сжатое парадоксальное описание сути | «управляемый хаос», «упругая жёсткость» |
| **Фантастическая** | допущение невозможного, снятие ограничений | «что если бы трения не было?» |

## Процедура

1. Сформулируй проблему «как дано».
2. Переформулируй её, сделай знакомое странным (постановка под вопрос очевидного).
3. Примени аналогии по очереди, собирая сырые идеи.
4. Сделай странное знакомым: перенеси идею обратно в реальность, сопоставь с ограничениями.
5. Отбери жизнеспособные идеи для проработки.

## Связь с ТРИЗ

Синектика — генератор, ТРИЗ — модель противоречия и проверка. Используй синектику для снятия инерции перед формулировкой ИКР/противоречия; полученные идеи проверяй на снятие противоречия.

## Ограничения применимости

- Аналогия не доказательство: «похоже на природу» ≠ «работает здесь».
- Чистый генератор без встроенной проверки — всегда дополняй `decision-analysis.md`.

## Проверка

- [ ] применено более одного типа аналогии;
- [ ] идеи перенесены обратно с явной проверкой ограничений;
- [ ] результат проверен на снятие противоречия, а не принят как есть.
