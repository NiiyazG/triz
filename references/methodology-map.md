# Карта методологии и маршрутизатор

## Три слоя проекта

1. **Поиск правильной задачи:** границы, функция, потоки, CECA, тримминг, S-кривая.
2. **Решение задачи:** противоречия, принципы, разделение ФП, Su-Field/76 SIS, FOS, эффекты, ARIZ-85C.
3. **Обоснование концепции:** реализуемость, риски, стоимость, доказательства, эксперимент.

## Быстрый выбор инструмента

| Наблюдение | Модель | Инструмент |
|---|---|---|
| Улучшение одного ухудшает другое | Техническое противоречие | изобретательские принципы, матрица как подсказка |
| Свойство требуется и не требуется в разных условиях | Физическое противоречие | принципы разделения |
| Нет нужного взаимодействия | Неполный/недостаточный Su-Field | 76 SIS, класс 1/2 |
| Взаимодействие вредно | Вредный Su-Field | 76 SIS, разрушение/изоляция/изменение поля |
| Компонент дорог или избыточен | Функциональная модель | тримминг и перенос функции |
| Неизвестно, чем выполнить функцию | Обобщённая функция | FOS и научные эффекты |
| Неясно, куда развивается система | Эволюционная модель | S-кривая и TESE |
| Простые инструменты не сняли ключевой конфликт | Мини-задача | ARIZ-85C route |

## Правило минимальной достаточности

Не загружай все справочники. Используй минимальный набор, который соответствует модели проблемы. Для сложных и критичных задач допускается несколько независимых маршрутов с последующим сравнением.
