# SIT — Systematic Inventive Thinking (Closed World)

> Статус: **canonical**. Источник: Jacob Goldenberg, Roni Horowitz, Amnon Levav, David Mazursky (на базе ТРИЗ). Первоисточники: https://en.wikipedia.org/wiki/Systematic_inventive_thinking ; https://www.sitsite.com/method/closed-world/

SIT — производная ТРИЗ, утверждающая, что изобретательские решения следуют ограниченному числу шаблонов, и накладывающая принцип **Closed World** (закрытого мира): решай, используя только элементы системы и её окружения.

## Принцип Closed World

Инновация «внутри коробки»: используй только элементы, уже существующие в системе или её ближайшем окружении. Это фокусирует мышление, ускоряет и удешевляет решение.

## Пять Thinking Tools

| Инструмент | Действие |
|---|---|
| **Subtraction** | удали существенный компонент и переопредели функцию |
| **Task unification** | заставь существующий компонент выполнять дополнительную функцию |
| **Multiplication** | скопируй компонент, но с изменением |
| **Division** | раздели компонент/функцию по времени или пространству |
| **Attribute dependency** | создай/разорви связь между двумя ранее независимыми атрибутами |

## Процедура

1. Выбери один закрытый мир (продукт, окружение, этап жизненного цикла).
2. Перечисли компоненты и атрибуты этого мира.
3. Примени шаблоны по очереди к компонентам.
4. Для каждой идеи: «реально ли это полезно?» (function follows form, не наоборот).
5. Отфильтруй по ценности и реализуемости.

## Связь с ТРИЗ

SIT-шаблоны — компактная переупаковка части ТРИЗ-приёмов (subtraction ≈ тримминг, division ≈ разделение ФП, attribute dependency ≈ параметрическое разделение). Полезен как быстрый генератор, ТРИЗ — как глубокая модель противоречия.

## Ограничения применимости

- Генератор, а не проверка: идеи требуют обоснования по `decision-analysis.md`.
- Не подходит для глубоких системных конфликтов — там ARIZ/OTSM.

## Проверка

- [ ] закрытый мир выбран явно и не расширяется «втихую»;
- [ ] каждый шаблон применён к конкретному компоненту;
- [ ] идеи отфильтрованы по ценности, а не по оригинальности.
