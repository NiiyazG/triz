# Пример: стандартный трек

**Симптом:** микросервисы ускорили независимые релизы, но инциденты стали дольше диагностироваться.

1. Главная функция: доставлять пользовательскую операцию через цепочку сервисов.
2. Ключевой недостаток: потеря сквозной причинной связи между событиями.
3. ТП: если увеличивать независимость сервисов, ухудшается сквозная наблюдаемость.
4. ФП: сервис должен быть автономным по реализации и частью единого наблюдаемого потока по диагностическим данным.
5. Разделение между системой и подсистемами: локальная автономия + единый контракт telemetry context.
6. Концепции: trace context standard; shared semantic conventions; correlation at gateway; event lineage store.
7. Новый риск: стоимость telemetry и утечка чувствительных данных.
8. Тест: MTTR, доля трассированных critical paths, telemetry cost, PII violations.
