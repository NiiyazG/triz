# TRIZ Skill 3.0 — гибридный решатель

Экспертный навык для системного решения изобретательских и противоречивых задач. Ядро — ТРИЗ (противоречия, ИКР, Su-Field/76 SIS, ARIZ-85C, TESE); к нему подключаются проверенные смежные методики, когда природа задачи вне чистого противоречия.

## Что изменено в версии 3.0

- добавлен смыслообразующий маршрутизатор **Cynefin** и честные выходы («обычная оптимизация», «сначала измерить», «данных недостаточно», «решения нет»);
- добавлена диагностика **природы задачи**: ТП / ФП / ложная дилемма / сеть проблем / неопределённость / невыполнимость / многокритериальный выбор;
- **ARIZ-85C** расширен до полного алгоритма 9 частей / 3 блока;
- добавлены 16 модулей смежных методик: TOC Evaporating Cloud, OTSM Network of Problems, C-K theory, морфологический анализ+CCA, Axiomatic Design, Decision Analysis (NASA/Pugh/Taguchi), SSM/CATWOE, Kepner-Tregoe, SIT, биомимикрия, синектика, латеральное мышление/6 шляп, Double Diamond, DOE, STPA;
- схема результата стала типизированной (противоречия с `anyOf`, `triz_tool` опционален), валидатор — со смысловыми проверками;
- расширены eval-наборы кейсами на новые методики и отрицательные случаи.

## Методологическая позиция

Навык отделяет:

1. классические инструменты ТРИЗ;
2. современную методологию MATRIZ;
3. смежные методики (TOC, OTSM, C-K, GMA, Axiomatic Design, decision analysis и др.);
4. авторские software-адаптации и эвристики.

Каждый внешний метод — модуль с маркировкой `canonical`/`adaptation`/`heuristic` и указанием первоисточника. Справочники не заменяют официальное обучение и доменную экспертизу. Для критичных решений обязательны проверка источников, расчёты, эксперимент и анализ безопасности.

## Опциональные интеграции

`tce` и `nc777-prompts` можно использовать как отдельные установленные навыки. Пакет `triz` полностью автономен и не содержит относительных ссылок на отсутствующие каталоги.
