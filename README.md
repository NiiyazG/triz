# TRIZ Skill 2.0

Экспертный навык для системного решения инженерных, продуктовых, организационных и software-задач методами ТРИЗ.

## Что изменено в версии 2.0

- основной `SKILL.md` превращён в компактный маршрутизатор;
- упрощённый workflow больше не называется АРИЗ;
- добавлены поиск ключевой задачи, функциональный анализ, потоки и CECA;
- добавлены способы разрешения физических противоречий;
- исправлена модель Su-Field и добавлена маршрутизация к 76 стандартным решениям;
- добавлены ресурсы, тримминг, FOS, S-кривая и TESE;
- авторские software-соответствия отделены от канонической ТРИЗ;
- внешние TCE/NC777-интеграции объявлены опциональными и не создают битых ссылок;
- добавлены eval-наборы, JSON Schema и автономные валидаторы;
- добавлен протокол экспертного ревью навыка.

## Быстрый запуск

```text
Примени TRIZ к задаче: как увеличить throughput API, не ухудшая консистентность и стоимость эксплуатации?
```

## Методологическая позиция

Навык отделяет:

1. классические инструменты ТРИЗ;
2. современную методологию MATRIZ;
3. авторские software-адаптации и эвристики.

Справочники не заменяют официальное обучение и доменную экспертизу. Для критичных инженерных решений обязательны проверка источников, расчёты, эксперимент и анализ безопасности.

## Опциональные интеграции

`tce` и `nc777-prompts` можно использовать как отдельные установленные навыки. Пакет `triz` полностью автономен и не содержит относительных ссылок на отсутствующие каталоги.
